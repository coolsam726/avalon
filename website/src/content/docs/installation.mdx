## Meet Avalon

Avalon is a Python web framework with expressive structure and first-class
`async`/`await` for ASGI. Create applications with `avalon new`, then drive them
with **Grail** — Avalon’s in-app CLI:

```bash
avalon new blog
cd blog
grail serve
```

Templates, routing, validation, localization, and the ORM all live behind the
`avalon.*` package. You write application code; Avalon boots the container,
compiles your routes, and serves them over ASGI.

:::note
Avalon is inspired by Laravel’s application shape. The public APIs, CLI, ORM,
and view engine are Avalon’s own — **Grail**, **Articulate**, and **Caliburn**.
:::

## Requirements

- Python **3.11** or higher
- `pip` and a virtual environment
- Node.js **18+** (optional but recommended) for the default Vite + Tailwind toolchain

## Creating an Avalon project

<Steps>

1. **Install Avalon** (once published, or from a local checkout while developing against main):

   ```bash
   pip install avalon
   # or, from a local clone of the framework:
   pip install -e /path/to/avalon
   ```

2. **Create a new application:**

   ```bash
   avalon new blog
   cd blog
   ```

3. **Create a virtual environment and install dependencies:**

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -e .                 # your app
   pip install avalon               # or -e /path/to/avalon during local development
   ```

4. **Install frontend dependencies (Vite + Tailwind):**

   ```bash
   npm install
   ```

5. **Start the development server:**

   ```bash
   grail serve
   ```

   Visit the URL Grail prints (typically `http://127.0.0.1:3000`). In another
   terminal, run `npm run dev` while iterating on CSS/JS.

</Steps>

:::tip[Grail]
With the virtualenv active, Avalon installs a `grail` console script — run
`grail serve`, `grail migrate`, `grail fiddle`, and so on. The root `grail`
file still works as `python grail …` if you prefer that form.
:::

## Directory structure at a glance

A fresh application looks like this:

```text
blog/
  app/
    http/controllers/
    models/
    providers/
  bootstrap/app.py
  config/
  database/migrations/
  database/seeders/
  resources/css/
  resources/js/
  routes/web.py
  routes/api.py
  package.json
  vite.config.js
  grail
```

Read more in [Directory Structure](/structure/) and [Asset Bundling](/asset-bundling/).

## Database drivers

SQLite works out of the box. For other engines, install the matching optional extra:

```bash
pip install avalon[pgsql]    # PostgreSQL
pip install avalon[mysql]    # MySQL / MariaDB
pip install avalon[sqlsrv]   # SQL Server
pip install avalon[oracle]   # Oracle (optional)
pip install avalon[db]       # all of the above
```

Configure connections in `config/database.py` — see [Database: Getting Started](/database/).
