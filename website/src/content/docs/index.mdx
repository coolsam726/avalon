Avalon is a web application framework with expressive, elegant syntax. We believe development must be an enjoyable, creative experience. Avalon attempts to take the pain out of development by easing common tasks used in many web projects — routing, validation, the database layer, and more — while keeping the Laravel mental model you already know.

Create apps with `avalon new`. Drive them with `python grail …`. Write controllers, models, and migrations the way you would in Laravel — with first-class `async`/`await` for ASGI.
